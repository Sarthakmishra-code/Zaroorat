
# Zaroorat – Rental Marketplace

Zaroorat is a full-stack rental marketplace website designed to bring different rental services under one platform. It allows users to list assets such as cars, bikes, houses, and PG accommodations for rent, while helping others explore available rental options.

The idea behind Zaroorat is to simplify rental discovery and listing by bringing multiple categories together in a single platform.

## 🚀 Live Deployment

**Live Website:** [Visit Zaroorat](https://zaroorat.vercel.app/)

## ✨ Features

- **Multiple Rental Categories:** Supports cars, bikes, houses, and PG accommodations.
- **User Listings:** Allows users to showcase their available assets for rent.
- **Rental Discovery:** Enables users to explore different rental options.
- **Unified Marketplace:** Combines vehicle and accommodation rentals on one platform.
- **Responsive Design:** Provides an accessible browsing experience across different devices.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Vercel

## 📌 Project Overview

Zaroorat was developed as an independent full-stack development project. The objective was to build a unified rental marketplace while gaining practical experience in frontend development, backend API integration, database management, and full-stack application development.
